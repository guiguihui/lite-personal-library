# LQ-D v0.1.0

LQ-D 的首个公开版本：一个本地优先、无数据库的个人知识库桌面客户端。

## 核心能力

- PyWebView 桌面界面与仅监听 `127.0.0.1` 的 FastAPI 本地服务。
- PDF / EPUB 导入，支持提取、清理、翻译、验证和论文笔记流水线。
- PageIndex V3 统一搜索、聊天、文档库与知识链接的数据视图。
- 本地 Markdown 事实源、可重建索引与增量构建。
- BYOK 模型配置，API Key 优先保存在系统 Keyring。
- 文档阅读、知识链接、反向链接和本地检索问答。

## 快速启动

```powershell
git clone https://github.com/guiguihui/lite-personal-library.git
cd lite-personal-library
python -m pip install -e .
python -m app.main
```

首次使用请先配置 Provider/API Key，导入资料并完成一次全量索引构建。完整流程和界面演示见项目 [README](../../README.md)。

## 已知限制

- 当前重点验证 Windows 10/11；其他平台尚未完成系统性验证。
- EPUB 推荐安装 Pandoc；DRM 加密或损坏文件无法导入。
- DOCX 尚未提供经过验证的提取器。
- 当前 Release 提供源码版本，独立安装包仍在持续完善。

## 数据与网络边界

个人内容与索引默认保存在本地 `data/` 且不进入 Git。纯本地导入与检索不依赖云服务；使用云端 LLM、MinerU 或其他远程 Provider 时才会产生相应网络请求。
